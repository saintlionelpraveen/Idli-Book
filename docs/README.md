## Maintenance

This documentation is maintained alongside the idli_book application. All changes to functionality should be reflected in the documentation.

### Update Process

1. Make changes to code
2. Update relevant documentation files
3. Update CHANGELOG.md
4. Increment version number
5. Commit changes with descriptive message
